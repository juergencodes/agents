# Example: Concise Shared Project State

```markdown
# Project State

## Goal
Prepare a public beta of the desktop app for small design teams.

## Current status
Core editing and export flows are implemented. Beta feedback collection is not yet set up.

## Confirmed decisions
- Beta distribution will use private invitations.
- The initial beta supports Windows only.

## Assumptions and open questions
- Assumption: The existing account system can support invitation codes.
- Open: Who will review and triage beta feedback?

## Next steps
- Verify invitation-code support.
- Set up a feedback intake and triage process.

## Key references
- Product requirements: `docs/product-requirements.md`
- Beta checklist: `docs/beta-checklist.md`
```

The state records durable decisions and the current handoff point. It does not list every completed implementation task or reproduce the linked documents.
