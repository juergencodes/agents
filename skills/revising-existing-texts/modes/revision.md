# Revision Mode

Use revision mode when the user asks to revise, rewrite, restructure, or replace the agreed text scope as a whole. The old text is source material, not a structure that must be preserved; content may be substantially changed or removed to meet the request.

Respect the user's requested scope. If it is unclear whether the user wants a full revision or localized edits, ask before editing. Do not expand a section-level request into a document-wide rewrite.

Unless the user requests another format, provide the complete revised text when a full revision was clearly requested. Before responding, verify that the result addresses the request and does not include unrelated changes.
